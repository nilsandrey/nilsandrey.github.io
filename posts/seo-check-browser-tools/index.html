SEO check browser tools

27 May, 2022

I'm using the Detailed SEO Extension by @ViperChill.

Features:

✅ checks for basic tags, canonical, robots, headings, links, images, schemas, and social graph objects.

I installed it to read JSON-LD schemas + canonical and basic tags with the same extension.

Loving in a close second the Ahrefs SEO Toolbar from @ahrefs. I like more the presentation of some parts like IMGs (more detailed), but I need the jsond-ld schema analysis as well which is not included.

Those are my selections for local work. After publishing at staging or production sites you can check more with the regular tools for each service provider. A shortcut for common checks can be summarized also online with this one from @woorank.
